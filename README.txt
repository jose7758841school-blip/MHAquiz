MY HERO ACADEMIA QUIZ

Files:
- index.html = student quiz
- teacher.html = master view
- style.css = website styling
- script.js = quiz questions and scoring

IMPORTANT:
This version stores scores in the browser's localStorage. That means it does NOT automatically share scores between different students/devices.

To make the master view receive scores from every device automatically, a cloud database such as Firebase or Supabase must be connected.

GitHub Pages:
1. Upload all four files to the root of your GitHub repository.
2. Open Settings > Pages.
3. Set the source to Deploy from a branch.
4. Select the main branch and /(root).
5. Save.
6. Your site will receive a github.io address after deployment.
7. The student quiz is index.html.
8. The current local master view is teacher.html.
